### The "Performance Booster" Engine
The core value of this repository lies in its structural prompt engineering. By embedding strict **Chain-of-Thought (CoT)**, multi-step validation loops, and explicit senior-level constraints directly into the system prompts, **these configurations force low-performance, lightweight, and free models to think and output at a premium tier.** 

Even when running on basic LLM backends, these instructions prevent lazy coding, enforce deep architectural reasoning, and eliminate generic boilerplate.
